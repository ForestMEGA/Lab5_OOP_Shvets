# Лабораторна робота 5 (Unit Testing)

 Головна мета цієї роботи — написати автоматичні модульні тести (Unit Tests) для перевірки класу Drone.

## Що я зробив у Lab-5:
1. Я створив у проекті окремий тестовий модуль на базі MSTest.
2. Я написав 16 тестів за шаблоном AAA (Arrange, Act, Assert).
3. Тести повністю перевіряють:
   * Правильні та неправильні вводи у властивості (Model, MaxSpeed).
   * Нестатичні методи (успішний політ та блокування зльоту при низькому заряді батареї).
   * Статичні змінні (країна-виробник) та метод класифікації дрона за вагою.
   * Роботу методів Parse та TryParse для збирання дрона з текстового рядка.
4. Я використав автоматичне створення об'єкта перед кожним тестом через TestInitialize та перевірку багатьох варіантів через DataRow.

## Як запустити тести:
Відкрийте проект у Visual Studio, знайдіть на верхній панелі вкладку "Тест" та оберіть "ЗапуститИ всІ тести".
